# Mission: LLM Agent Skills

## Why
To understand how LLM agent skills work — the concept, history, and mechanism — so I can write better skills, use existing ones effectively, and participate in the emerging ecosystem of prompt-based agent tooling.

## Success looks like
- I can explain what agent skills are and how they differ from plain prompts
- I understand how agents discover, route to, and invoke skills
- I know the key milestones and players in this space's history
- I can write my own well-structured skill files

## Constraints
- Focus on Matt Pocock's skills framework (what I'm already using)
- Ground learning in real examples from this workspace
- Keep lessons tight and completable in minutes

## Out of scope
- Building custom agent frameworks from scratch
- Deep dive into ReAct, planning, or other agent architectures (unless directly relevant)
- Non-engineering skill systems (yoga, fitness, etc.)
