# Agent instructions

## Agent skills

### Issue tracker

GitHub Issues are used for engineering work tracking. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical triage labels are used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context domain docs are used with a root `CONTEXT.md` plus `docs/adr/`. See `docs/agents/domain.md`.
